## How I work

- **Pick the metric before the model.** On imbalanced data the same result tells opposite stories
  depending on whether you report accuracy or F1 — so the metric is a decision, not a default.
- **Count things before you model them.** The dangerous data bugs do not raise errors. A duplicate
  join, a midnight rollover, a silently text-typed column — they all return plausible wrong answers.
- **Say what did not work.** My portfolio reports a defect recall of 0.28 and an RL agent that
  never converged, because a result you cannot defend is worth less than a failure you understand.
- **Translate into the unit the business counts in.** "0.7 percentage points" survives a meeting.
  "700 defective products a day" does not.
