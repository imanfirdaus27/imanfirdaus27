## How I work

**Choose the metric before the model.** On imbalanced data the same result tells opposite stories
depending on whether accuracy or F1 is reported. The metric is a decision, not a default.

**Count things before modelling them.** The costly data problems do not raise errors. A duplicate
join, a midnight rollover, a column silently typed as text: each returns a plausible wrong answer.

**Report what did not work.** My portfolio states a defect recall of 0.28 and a reinforcement
learning agent that never converged, because a result that cannot be defended is worth less than a
failure that is understood.

**Translate into the unit the business counts in.** A drop of 0.7 percentage points survives a
meeting. Seven hundred misclassified products a day does not.
